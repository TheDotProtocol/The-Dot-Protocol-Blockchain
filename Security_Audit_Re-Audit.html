Remediation Details

✅ C-01 + C-02: TimelockController + Rebase Cap

Contract: DPC20.sol + TimelockController.sol

  • Added TimelockController.sol — OpenZeppelin-style time-delayed execution with proposer/approver roles
  • DPC20 rebase capped at ±5% per 30-day period via REBASE_CAP_BPS = 500
  • Proportional cap calculation: if 15 days elapsed, only 2.5% cap available
  • Added supplyAtLastRebase snapshot for accurate calculations
  • Emergency emergencyRebaseAndPause() function for crisis situations
  • All role-based access via OpenZeppelin AccessControl (multi-sig ready)

✅ C-03: Hardcoded Private Key Removed

File: packages/contracts/scripts/deploy-mock-tokens-ethers.js

  • Private key completely removed from source code
  • Script now requires DEPLOYER_PRIVATE_KEY environment variable
  • Crashes with clear error message if env var not set
  • .env file properly gitignored

✅ C-04 + H-04: JWT Security Overhaul

File: apps/hexchange-api/src/middleware/auth.js

  • Replaced custom HMAC implementation with jsonwebtoken library
  • JWT_SECRET required via environment variable — server crashes if not set
  • No fallback secret — eliminates hardcoded key risk
  • Constant-time signature verification (library handles this)
  • Algorithm restriction: only HS256 allowed

✅ C-05: CORS Restricted

Files: All 3 docker-compose.yml files

  • Mainnet: Restricted to hexchange.YOUR_DOMAIN.com, YOUR_DOMAIN.com, www.YOUR_DOMAIN.com
  • Testnet: Same restrictions + localhost for development
  • API: CORS middleware updated with explicit origin whitelist
  • Development mode allows all origins (for local development)

✅ C-06: Bridge Hardened

Contract: Bridge.sol

  • Nonce replay protection: each attestation nonce can only be used once
  • Quorum requirement: quorumRequired validators must approve
  • Rate limiting: per-address daily transfer limits + per-tx max amount
  • Emergency pause capability
  • Configurable bridge parameters per chain

✅ H-01: Escrow ETH Withdrawal

Contract: HexchangeEscrow.sol

  • Added withdrawETH(uint256 amount) — admin can withdraw specific amounts
  • Added withdrawAllETH() — admin can withdraw full balance
  • ETH received via acceptAndPay() is now tracked in ethReceived field
  • Added ETHWithdrawn event for transparency
  • Rate limiting: MAX_DISPUTES_PER_DAY = 10 per user

✅ H-02: Order Auth Enforced

File: apps/hexchange-api/src/index.ts

  • Order submission now requires authMiddleware (was optionalAuth)
  • Cancel endpoint now requires authMiddleware (was unauthenticated)
  • Added input validation: numeric range checks, side validation
  • Added per-user rate limiting: 20 orders per user per minute

✅ Router Bug Fix

Contract: HexchangeRouter.sol

  • Fixed critical bug: Router was not transferring input tokens to Pair before calling swap()
  • Added IERC20(input).safeTransferFrom(msg.sender, pair, amountIn) in _swap()
  • This was causing all swaps to revert with "INSUFFICIENT_INPUT_AMOUNT"
