🐛 Bug Bounty Program

The Dot Protocol — Help us secure the ecosystem
Launched: September 2, 2026 Platform: Immunefi Total Pool: $500,000

Overview

The Dot Protocol is committed to security. We invite security researchers and white-hat hackers to find vulnerabilities in our smart contracts, infrastructure, and applications. We offer competitive rewards for responsible disclosure of valid security issues.

🎯 Scope

Our bug bounty covers the entire Dot Protocol ecosystem:

  • Smart Contracts: DPC20, Hexchange (Factory, Router, Pair, Escrow, Presale), Oracle, Stabilization, Governance, Bridge, CCIPBridge
  • Infrastructure: Besu QBFT chain, validator consensus, RPC endpoints
  • Applications: Hexchange DEX, Presale app, Explorer, Wallet, 3Dot Pay
  • Backend: Hexchange API, authentication, order book engine

Out of Scope

  • Already known issues documented in our security audit reports
  • Issues in third-party dependencies (OpenZeppelin, Chainlink) — report to them directly
  • Centralization risks that are documented and accepted (e.g., single oracle admin — being decentralized)
  • UI/UX issues that don't affect fund security
  • Rate limiting bypasses on testnet only
  • Issues requiring physical access to validator nodes

Submission Guidelines

How to Submit

  1. Find a vulnerability in our smart contracts or infrastructure
  2. Write a clear report with:
    • Vulnerability description
    • Step-by-step reproduction steps
    • Impact assessment (what could an attacker gain?)
    • Potential fix recommendation
    • Your wallet address for reward payment
  3. Submit via Immunefi: https://immunefi.com/bounty/dotprotocol
  4. Wait for review — we aim to respond within 48 hours

Responsible Disclosure

  • Do NOT exploit vulnerabilities on mainnet with real user funds
  • Do NOT publicly disclose the vulnerability before we've patched it
  • Do test on the Chennai testnet (chain ID 1545) — RPC: http://rpc-chennai.YOUR_DOMAIN.com
  • Do provide sufficient proof-of-concept code
  • Do allow 90 days for us to patch before any public disclosure

Eligibility

  • You must be the first person to report the vulnerability
  • The vulnerability must be previously unknown to us
  • You must not be a current employee or contractor of The Dot Protocol
  • US persons and sanctioned country residents are excluded from this program
  • You must comply with all applicable laws

Program Rules

  1. First come, first served — only the first valid report receives a reward
  2. Multiple reports of the same issue: only the most detailed/impactful receives reward
  3. We reserve the right to modify reward amounts based on severity and impact
  4. We will not pursue legal action against researchers who follow responsible disclosure
  5. This program may be modified or terminated at any time
  6. All decisions by The Dot Protocol team are final
