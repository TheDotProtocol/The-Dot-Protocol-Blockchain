# DPC20 Presale App

Standalone presale dapp for Dot Protocol — private whitelist, MetaMask, Chennai testnet.

**Dev:** `npm run dev:presale` from repo root → http://localhost:3001

## Features

- Redesigned dashboard layout (progress + purchase panel)
- Auto-connect MetaMask → Chennai testnet (chain 1545)
- Auto-import DPC20/TDOT token contract
- Live TDOT balance display when connected
- Network status indicator

## Environment

```bash
# Optional — link back to main website
NEXT_PUBLIC_WEBSITE_URL=http://localhost:3000
```
